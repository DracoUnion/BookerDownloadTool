# BookerDownloadTool 代码结构

一个面向中文互联网内容的命令行下载工具，支持从 GitHub 电子书、轻小说站（wenku8）、知乎、Discuz 论坛、知识星球、语雀、飞书、微信公众号、Anna's Archive、Medium、arXiv 等多个来源批量抓取内容并生成本地文件（EPUB / Markdown / 文本 / JSONL）。

命令行入口三个：`BookerDownloadTool`、`bdt` 与 `dl-tool`，均映射到 `BookerDownloadTool.__main__:main`（见 pyproject.toml 的 `[project.scripts]`），即 `python -m BookerDownloadTool` 也可直接运行。自带数十个子命令，如 `gh-book`、`ln`/`batch-ln`/`fetch-ln`、`wenku`、`zhihu-ques/zhihu-topic/zhihu-topics`、`dz`/`batch-dz`/`fetch-dz`、`zsxq`、`whole-site`/`exp-whole-site`、`links`/`sitemap`/`links-epub`、`wx`、`uqer`/`batch-uqer`、`freembook`、`yuque`/`batch-yuque`、`feishu`/`feishu-all`、`arxiv-fetch`、`gh-repo-fetch`、`hkrnws-fetch/hkrnws-range`、`pixabay`、`annas`/`annas-batch`/`annas-fetch`/`annas-dedup`、`xhs`、`kaggle`、`twitter`、`weibo`、`ext-cookies` 等。

代码全部位于 `BookerDownloadTool/` 包内，按职责分为八类模块：

## 1. 入口与命令注册

+ `__main__.py` — 唯一 CLI 入口。构建顶层 `argparse` 解析器（含 `-v/--version`、无头模式 `-H/--no-headless` 及 `-m/--model`、`-k/--key`、`--host`、`-r/--retry`、`-tm/--temp`、`-D/--debug` 等公共参数），逐一调用各源模块的 `reg_subparser` 注册子命令，最后按 `args.func(args)` 派发。
+ `__init__.py` — 包元信息（`__version__` = 2025.4.1.0，作者 wizardforcel，SATA 协议）。
+ 每个源模块暴露 `reg_subparser(subparsers)`，在其中通过 `subparsers.add_parser("<命令名>")` 注册子命令并指定 `func=xxx` 入口函数。

## 2. 共享基础设施

+ `util.py` — 通用工具函数，跨命令复用：Camoufox/Playwright 浏览器驱动创建（`camou_create_driver`、`plrt_create_driver`）、浏览器 Cookie 导出与解析（`read_js`、`extract_cookies*`、`parse_cookie`、`cookie_str_to_dict`、`cookie_dict_to_str`）、HTTP 请求重试（`request_retry`）、文件/目录安全操作（`safe_mkdir`/`safe_rmdir`/`safe_remove`）、图片优化（`opti_img`、`anime4k_auto`）、Markdown 正文提取（`md_body`）、`md5`/`to_kebab`/`fname_escape` 等。
+ `openai.py` — LLM 客户端层：`OpenAIClient` 类封装 `request_retry` 等；`ToolsMixin` 工具型命令混入；`base_schema`/`func_schema`/`params_schema`/`model_schema`/`str_list_schema`/`str_str_map_schema` 等 Schema 构造助手；`dispatch_tools` 按模型返回的 tool call 分发到工具方法。

## 3. 电子书与文档下载子命令

+ `dl_gh_book.py` — `gh-book`：抓取 GitHub 仓库的 `SUMMARY.md` 图书目录，按章节生成 EPUB。
+ `lightnovel.py` — `ln`/`batch-ln`/`fetch-ln`：wenku8 轻小说站下载、批量下载、按日期抓取小说 id。
+ `wenku.py` — `wenku`：百度文库预览文档，按页下载图片合成 PDF。
+ `freembook.py` — `freembook`：按 ssid 区间抓取 freembook 图书信息，输出 JSONL。
+ `annas.py` — `annas`/`annas-batch`/`annas-fetch`/`annas-dedup`：Anna's Archive 单本下载、批量下载、搜索、按标题相似度去重；内含滑块验证码识别（`preprocess_captcha`/`recognize_captcha`）与 Playwright 页面等待工具。
+ `kaggle.py` — `kaggle`：抓取 Kaggle 比赛笔记本（slug）并导出，无需 API Key，复用浏览器内部接口，输出 EPUB。
+ `arxiv.py` — `arxiv-fetch`：按分类和日期区间抓取 arXiv 论文 id 列表。

## 4. 社区与论坛子命令

+ `discuz.py` — `dz`/`fetch-dz`/`batch-dz`：Discuz 论坛帖子/版块抓取，生成 EPUB（超 100MB 自动分卷），支持断点续传（`exi_list`）。
+ `zhihu.py` + `zhihu_sign.py` — `zhihu-ques`/`zhihu-ques-batch`/`zhihu-topic`/`zhihu-topic-batch`/`zhihu-topics`：知乎问题下的回答、话题下的问题及子话题抓取，走官方 API 并计算 `x-zse-93`/`x-zse-96`/`x-zst-81` 签名；`zhihu_sign.py` 用 quickjs 执行前端模块 1514 的原始 JS 代码（详见 `doc/zhihu_sign.md`）。
+ `weibo.py` — `weibo`：基于微博移动端搜索接口按关键词抓取博文，输出 CSV/JSON/Markdown。
+ `twitter.py` — `twitter`：基于 Scweet 抓取 Twitter/X 关键词推文，输出 CSV/JSON/Markdown。
+ `xhs.py` — `xhs`：搜索小红书笔记，保存全量文本与图片，输出 md 与图片文件。
+ `hkrnws.py` — `hkrnws-fetch`/`hkrnws-range`：抓取 HackerNews 某天 / 某日期区间的链接。
+ `medium.py` — `medium`：抓取 Medium 博客按日期发布的文章链接。

## 5. 知识库与协作子命令

+ `yuque.py` + `yuque_external.py` — `yuque`/`batch-yuque`：语雀知识库文章 / 批量抓取，输出 EPUB；`yuque_external.py` 提供 `get_article` 文章内容提取（书籍 ID、标题、正文、card 图片/代码块解析）。
+ `feishu.py` — `feishu`/`feishu-all`：抓取飞书单篇文档或 wiki 整棵节点树，输出 Markdown（含图片目录）。
+ `zsxq.py` — `zsxq`：下载知识星球某个圈子某个时间段的全部内容，输出 EPUB。

## 6. 公众号、链接与整站子命令

+ `wx.py` + `wx_external.py` — `wx`：从公众号文章 Excel 导出批量生成 EPUB，按公众号分组、按月切片，调用 EpubCrawler 生成；`wx_external.py` 提供 `get_article` 文章提取。
+ `links.py` — `links`/`sitemap`/`links-epub`：按分页抓取页面链接、抓取站点地图链接、把链接列表批量生成 EPUB。
+ `webarchive.py` — `web-archive`：从 Wayback Machine CDX 抓取某域名存档 URL。
+ `whole_site.py` — `whole-site`/`exp-whole-site`：爬取整站可达 URL 并入 SQLite（`UrlRecord` 记录模型），再导出 URL 列表。

## 7. 图片子命令

+ `pic.py` — `pixabay`：按关键词批量下载 Pixabay 图片。
+ `nhentai.py` — nhentai 抓取（信息提取、图片下载、已存在去重、文件名修复）。

## 8. 辅助工具

+ `ext_cookie.py` — `ext-cookies`：从本机浏览器（chrome/chromium/edge/firefox 等）导出指定域名的 Cookie，打印到标准输出，供其他命令的 `-c/--cookie` 或环境变量使用。
+ `process_img_md.py` — Markdown 中图片下载与重写（`process_img_md`/`tr_download_img`/`tr_download_img_safe`）。
+ `module1514.js` — 知乎签名加密器 ZP 的原始 JS 模块，由 `zhihu_sign.py` 经 quickjs 执行。
+ `patch_env_mock_wasm.js` / `stealth.min.js` — 浏览器环境补丁与反自动化检测 JS。

项目还包含 `doc/` 子目录（站点 API 逆向资料：`xhs_api.md` / `xhs_api_2.md`、`zhihu_api.md` / `zhihu_sign.md` / `zhihu_sign_anls.md`、`wenku_api.md`、`so_tmpl.md`、`browser_detect_patch.md，以及 `doc/js/` 与 `doc/py/` 的逆向脚本）、`.pytest_cache/`（表明有 pytest 测试）、`_xhs_data/` 与 `_xhs_decompile/`（小红书接口数据与反编译资料，非源码）、`dist/`（已打包的 wheel/sdist）。
