# 行业搜索关键词

打造行业知识库，第一步是建立一套**可扩展的行业骨架**，第二步是为每个行业设计**贴合百度文库检索逻辑的关键词组合**。百度文库资源库自身也采用了“专业资料”的分类逻辑，将行业内容归入 IT/计算机、人文社科、农林渔牧、医药卫生、工程科技、经管营销、自然科学等板块。以下以《国民经济行业分类》（GB/T 4754—2017）的 **20 个门类**为骨架，同时融合百度文库的实际分类习惯，为每个行业提供可直接用于文库检索的关键词组。

### 二、在百度文库中“搜得准”的关键策略

光有关键词列表还不够，百度文库的检索质量很大程度上取决于**指令组合**和**关键词层级**的运用。

**1. 用 `site:` 把搜索范围钉死在文库内**
在百度搜索框中输入 `关键词 site:wenku.baidu.com`，可以避免被其他网页干扰，直接返回百度文库的文档结果。

**2. 用 `filetype:` 直接锁定文档形态**
行业知识库通常更需要方案、报告、标准、模板等“可复用”文档。在关键词后加上 `filetype:pdf`（方案/报告/标准）或 `filetype:doc`（管理制度/合同模板），可以跳过低价值的零散问答和摘要页。

**3. 用“上位词/下位词”扩展检索半径**
行业关键词不能只搜“核心名词”。以“制造业”为例，上位词是“工业”“第二产业”，下位词是“汽车制造”“电子设备制造”“质量管理”“精益生产”等。百度文库的检索讲座也特别强调，上位词与下位词组合可以有效避免“搜一个词只出一类结果”的漏检问题。

**4. 组合示例**
- 为“汽车制造业”建库：`汽车制造 质量管理 filetype:pdf site:wenku.baidu.com`
- 为“基层医疗”建库：`社区卫生 院感控制 诊疗规范 filetype:pdf site:wenku.baidu.com`
- 为“建筑施工企业”建库：`施工组织设计 安全文明施工 验收规范 filetype:pdf site:wenku.baidu.com`

**5. 善用文库内部的“免费”筛选**
在百度文库站内搜索时，结果页顶部有筛选工具，勾选“免费”可以优先获取可直接下载的文档，适合知识库搭建初期的批量素材采集。


**一点补充**：上述 20 个门类覆盖的是国家统计层面的“全口径行业”。如果你希望知识库更聚焦于**商业和职场场景**，可以优先深耕其中与组织运营关联最紧密的 10—12 个行业（如制造业、信息技术、金融、建筑、批发零售、教育、卫生、商务服务、物流、文化传媒），再逐步向上下游延伸。每个行业的关键词列表也可以作为你后续在百度文库中批量检索、筛选、归档的“检索底表”来使用。
